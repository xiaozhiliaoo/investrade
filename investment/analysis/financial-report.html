概览

资产：有多少钱
负债：欠多少钱
收入：赚多少钱
成本：花多少钱
利润：剩多少钱
现金：攒多少钱
分红：分多少钱
估值：给钱定价

经营为正 → 赚钱：净现金流入
经营为负 → 赔钱：主业消耗现金 (真亏损/利润没成现金)

投资为正 → 收钱：卖资产/收回投资/定期到期/投资收益/卖子公司。
投资为负 → 花钱：建产能/买理财定期/对外投资/拆借资金

筹资为正 → 借钱 (主被动)/增发股票/收到关联方资金
筹资为负 → 还钱 (主被动)/分红/回购/支付利息

经营 +，投资 −，筹资 −（成熟健康型，自己赚钱、自己投资、还回报股东）

经营 +，投资 −，筹资 +（扩张型，主业赚钱，但扩张更猛，靠融资补差额）

经营 +，投资 +，筹资 −（收缩回笼型）

经营 +，投资 +，筹资 +（囤钱型，账上现金暴增）

经营 −，投资 −，筹资 +（烧钱扩张型，融资能不能持续和未来能不能盈利）

经营 −，投资 −，筹资 −（危险型，主业不赚钱、还在花钱、还要还债，现金快速消耗）

经营 −，投资 +，筹资 +（断臂求生型，靠卖资产和融资维持现金流）

经营 −，投资 +，筹资 −（最危险型，卖资产还债）

十亿-小盘/百亿-中盘/千亿-大盘/万亿-超大盘

折旧、摊销、减值

高分红行业：煤炭，行业进入成熟期，不需要再大量投资，高股息不等于高回报。如果借钱分红，每年利息支出侵蚀利润，长期损害股东价值。

财务诊断

盈利能力 (赚钱能力)：毛利润，净利率，总资产收益率，净资产收益率

成长能力 (规模增长)：营收，利润，净利润，总资产

偿债能力 (还债能力)：速动比率，流动比率，资产负债率，现金比率

运营能力 (资产周转)：应收账款周转率=营业收入/应收账款，存货周转率=营业成本/存货，流动资产周转率=营业收入/流动资产，总资产周转率=营业收入/总资产，负债权益比率=总负债/股东权益

现金流 (利润转真钱)：销售现金比率=经营活动现金净流量/营业收入 ，净利润现金含量=经营活动现金净流量/净利润，现金营运指数=经营活动现金净流量/ (净利润+ 折旧摊销等非付现成本)，现金满足投资比率=经营活动现金净流量/ (资本支出 + 存货增加 + 现金股利)，现金流量净额增长率

ROE = 净利率 * 总资产周转率 * 权益乘数

ROE = 净利润/营业收入 (每1元收入赚多少) × 营业收入/总资产 (每1元资产产生多少收入) × 总资产/净资产 (用多少杠杆) =

盈利能力 × 运营能力 × 财务杠杆

周转把资产负债表和利润表连接起来。周转是运营能力的核心，因为衡量的是公司最根本的一件事：用资产创造收入的效率。

周转慢往往是问题的根源：应收账款周转慢（利润好看但钱收不回来），存货周转慢（产品滞销，库存贬值），总资产周转慢（大量资产闲置或低效）

沃尔玛：净利率低，总资产周转快，薄利多销，快速周转。 - 生意逻辑：高周转，薄利多销，零售天然快

茅台：净利率极高，周转率不算快，靠高毛利赚钱。 - 生意逻辑：高毛利

银行：总资产周转率极低，但靠高杠杆放大ROE。 - 生意逻辑：高杠杆

ROE是企业分析的起点。所有生意最终都要回答“股东回报多少”。ROE是结果，不是原因

金融企业：ROE + 不良率 + 资本充足率，资产质量、资本充足率、流动性

重资产：ROE + 现金流 + 折旧政策，现金流、EBITDA、资产久期

高成长：ROE + 收入增速 + 毛利率趋势，收入增速、用户增长、毛利率趋势、研发管线

轻资产：ROE + 人均产出 + 客户留存

周期行业：ROE + 周期位置 + 成本优势

周转率=流量/存量

收入->资产：总资产周转率 = 营业收入 / 总资产

利润->现金：净利润现金含量 = 经营现金流 / 净利润

资产->现金：现金循环周期 = 存货周转天数 + 应收周转天数 − 应付周转天数

应收账款周转率：应收账款 → 经营现金流

存货周转率：存货 → 经营现金流

现金循环周期= 存货周转天数 (货压多久) + 应收账款周转天数 (钱欠多久) − 应付账款周转天数 (钱拖多久)

餐厅为例

比如一家餐厅：

利润表：营业收入 100W，营业成本 70W，销售/财务/管理/研发 20w，净利润 10W

资产负债表：总资产200W，应收账款 30W，存货 20W

现金流量表：经营现金流 5W

总资产周转率=100/200=0.5（资产效率偏低）

应收账款周转率=100/30=3.3（回款偏慢）

存货周转率=70/20=3.5（库存一般）

净利润现金含量=5/10=0.5（利润含金量差）

大量利润停留在应收账款和存货。

如果只看净利润 10W，会觉得餐厅赚钱，

加上总资产 200W，发现 ROE 只有 5%，回报偏低，

加上经营现金流 5W，发现利润含金量差，

再用周转率拆解，才能定位到底是应收、存货还是固定资产的问题。

比如另一家餐厅：

利润表：营业收入 100W，营业成本 70W，销售/财务/管理/研发 20w，净利润 10W

资产负债表：总资产200W，应收账款 2W，存货 5W

现金流量表：经营现金流 5W

应收账款周转率 = 100 / 2 = 50 次 → 回款极快，约7天一次。

存货周转率 = 70/5 = 14 次 → 约 26 天一次，对餐厅合理。

总资产周转率 = 100/200 = 0.5 → 这个仍然偏低。

193W是店面装修、厨房设备固定设备，总资产周转率低，固定资产投入过大或收入不足。

回本 = 累计净利润 ≥ 初始投入

回报率 = 年纯利÷总投资额，投20万一年赚20万，100%的年回报率意味着12个月回本。半年回本意味年回报率要达到200%。

很多餐饮：用创业的方式打工，而且这份工比上班累十倍，没有周末没有假期，全年无休，且还有损失的风险。
